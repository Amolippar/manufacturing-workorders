# Manufacturing Work Order Management System

Industrial work-order tracking system enabling plant managers, supervisors, and machine operators to coordinate production schedules, monitor stage progress, and log QA inspections.

## Tech Stack
- **Backend**: Java 17/21, Spring Boot 3, Spring Data JPA, Hibernate, MySQL 8.0
- **Frontend**: React.js, Tailwind CSS, Lucide Icons, Axios
- **Architecture**: N-Tier Architecture with ACID State Machines

## Features
- 5-Stage Floor Shop Kanban Board (Backlog -> Machining -> Assembly -> QA -> Dispatch)
- OEE (Overall Equipment Effectiveness) and Production Health Metrics
- Station Operator and Machine Tool Assignment
- Tolerance and Quality Control Sign-Offs
